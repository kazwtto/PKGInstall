## Overview

A PKG installer based on [Muggle345/PKGInstall](https://github.com/Muggle345/PKGInstall/) with **Modern Interface** and **ZAR Support**.

## Linux Dependencies

The following dependencies are required to build and run the application outside the AppImage distribution.

<details>
<summary><b>Ubuntu / Debian</b></summary>

```bash
sudo apt install build-essential qt6-base-dev qt6-tools-dev
```
</details>

<details>
<summary><b>Fedora</b></summary>

```bash
sudo dnf install qt6-qtbase-devel qt6-qtbase-private-devel qt6-qttools-devel
```
</details>

<details>
<summary><b>Arch Linux</b></summary>

```bash
sudo pacman -S base-devel qt6-base qt6-declarative qt6-multimedia qt6-tools
```
</details>
